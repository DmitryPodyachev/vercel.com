bhf firmware builder

Backend сборки прошивок для bhf.pp.ua: компилирует скетч Arduino (avr-gcc, ArduinoCore-avr 1.8.6) и отдаёт zip с .hex, исходником и инструкцией по прошивке для Windows, macOS и Ubuntu.

ПлатыArduino Uno (ATmega328P)
ПрошивкиBlink LED: светодиод переключается раз в 2 с; Blink LED fast: раз в 0,5 с. Сообщение выводится в Serial (115200 бод).
Состояние…

API

GET  /api/build                                   состояние сборщика
POST /api/build {"id":"<job id>"}                  собрать задание из очереди bhf.pp.ua, zip в R2
POST /api/build {"device":"arduino_uno","firmware":"blink","text":"Hello"}   zip сразу в ответе
curl -s -X POST https://odesa2027.vercel.app/api/build -H 'content-type: application/json' \
  -d '{"device":"arduino_uno","firmware":"blink_fast","text":"Hello"}' -o fw.zip
